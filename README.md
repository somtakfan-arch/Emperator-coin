# Эмператор: от бомжа до миллиардера

Текстовая браузерная игра-симулятор жизни. Игрок вводит любое имя, после
чего судьба случайно выдаёт одного из 25 персонажей со своими
характеристиками (возраст, работа, имущество, деньги, семья, аллергия),
а дальше нужно пройти через 400+ случайных поворотов судьбы, чтобы дойти
от бомжа (или обычного человека, или миллионера) до миллиардера — либо
разориться, попасть в тюрьму или не пережить очередное испытание.

Чистый статический сайт: HTML/CSS/JS без сборки и зависимостей.

## Структура

```
index.html        разметка всех четырёх экранов
css/style.css      стили
js/utils.js        общие хелперы (форматирование денег, рандом, тиры)
js/characters.js    банк из 25 персонажей
js/events.js        генератор банка из 400+ событий
js/engine.js         игровое состояние, ходы, условия окончания игры
js/main.js            рендер экранов и обработка кликов
netlify.toml       конфиг деплоя на Netlify
```

## Локальный запуск

Файлы статические, достаточно любого http-сервера:

```bash
python3 -m http.server 8080
# затем открыть http://localhost:8080
```

## Деплой на Netlify

1. Залить репозиторий на GitHub (или загрузить папку целиком через
   Netlify Drop — https://app.netlify.com/drop).
2. В Netlify: **Add new site → Import an existing project**, выбрать
   репозиторий.
3. Build command оставить пустым, Publish directory — `.` (корень).
   Файл `netlify.toml` уже задаёт эти настройки автоматически.
4. Deploy site — через минуту сайт будет доступен по ссылке `*.netlify.app`.

Никакого бэкенда, базы данных или переменных окружения не требуется —
вся игра работает полностью на стороне клиента.
