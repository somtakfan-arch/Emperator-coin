# BedBots — ИИ-боты для BedSMP

Боты ходят по миру (через Citizens) и общаются в чате на русском через бесплатный Groq AI.

## Что нужно
1. **Paper 1.21.11** (сервер)
2. Плагин **Citizens** (dev-сборка под 1.21.11) — кинуть в папку `plugins/`
3. Бесплатный ключ Groq — https://console.groq.com → API Keys (без карты)

## Сборка
```
mvn clean package
```
Готовый плагин: `target/BedBots.jar` → кинуть в `plugins/`, рядом должен лежать `Citizens.jar`.

## Настройка
1. Запусти сервер один раз — создастся `plugins/BedBots/config.yml`
2. Впиши свой ключ Groq в `groq.api-key`
3. Настрой ботов в секции `bots` (имя, скин, характер)
4. `/bedbots reload` — применить без рестарта

## Команды
- `/bedbots reload` — перечитать конфиг и пересоздать ботов
- `/bedbots respawn` — пересоздать ботов
- `/bedbots remove` — убрать ботов

## Как это работает
- Боты не плодятся: при старте плагин удаляет своих старых NPC (по метке) и спавнит заново.
- Отвечают не на всё: шанс ответа `reply-chance`, плюс всегда — если упомянули ник.
- Кулдауны (`global-cooldown`, `bot-cooldown`) не дают спамить и нарушать правило про флуд.
- В system-промпт зашиты рамки: только русский, коротко, без мата/угроз/18+/политики, не палиться что бот.

## Если при запуске ошибка про Gson
Paper обычно отдаёт Gson сам. Если вдруг `NoClassDefFoundError: com.google.gson` —
скажи мне, добавлю shade-плагин в pom, чтобы Gson паковался внутрь jar.
