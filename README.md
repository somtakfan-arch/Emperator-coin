# Эмператор: от бомжа до миллиардера

Текстовая браузерная игра-симулятор жизни. Игрок вводит любое имя, после
чего судьба случайно выдаёт одного из 25 персонажей со своими
характеристиками (возраст, работа, имущество, деньги, семья, аллергия),
а дальше нужно пройти через 400+ поворотов судьбы, чтобы дойти от бомжа
(или обычного человека, или миллионера) до миллиардера — либо
разориться, попасть в тюрьму или не пережить очередное испытание.

Все исходы — детерминированные (никакой удачи): решают характеристики
персонажа (репутация, здоровье, энергия, накопленные черты характера)
и мини-игры на реакцию/расчёт/точность.

Помимо основной истории есть вкладки:
- **Инвентарь** — еда, одежда, машины, сумки, часы, электроника,
  ювелирка (все названия брендов вымышленные, не привязаны к реальным
  торговым маркам — это просто игровой флавор).
- **Магазин** — покупка вещей и кейсов. Кейс открывается мини-игрой
  "Поймай момент": точность решает, какая вещь выпадет, а не рандом.
- **Доктор** — платные визиты лечат и продлевают жизнь; если ходить
  регулярно, до предельного возраста можно не дожить никогда.
- **Казино** — отдельные ставки на мини-игры (тайминг/счёт/реакция).
- **Аукцион** и **Таблица лидеров** — межигровые функции, требуют
  аккаунт (Firebase).
- **Админ-панель** (пароль `empc`) — поиск игрока и выдача/списание
  денег.

Имущество из инвентаря учитывается в "чистой стоимости" — на неё же
(а не только на наличные) смотрит переход в следующий социальный слой,
так что дорогие покупки и продажи на аукционе реально помогают
разбогатеть быстрее.

Чистый статический сайт: HTML/CSS/JS без сборки. Firebase — единственная
внешняя зависимость, и она полностью необязательна: без неё игра
работает целиком локально (кроме аккаунта/лидеров/аукциона).

## Структура

```
index.html            разметка всех экранов и вкладок
css/style.css          стили
js/utils.js             общие хелперы (форматирование денег, рандом, тиры)
js/characters.js         банк из 25 персонажей
js/items.js               каталог предметов инвентаря и кейсов
js/minigames.js            три мини-игры: тайминг / счёт / реакция
js/events.js                банк из 440+ событий (детерминированные исходы)
js/engine.js                 состояние игры, ходы, инвентарь, доктор, барьер уровня
js/firebase-config.js         СЮДА вставляешь свой конфиг Firebase
js/cloud.js                    обёртка над Firebase Auth + Firestore
js/inventory.js                 вкладки "Инвентарь" и "Магазин"
js/doctor.js                     вкладка "Доктор"
js/casino.js                      вкладка "Казино"
js/auction.js                     вкладка "Аукцион"
js/leaderboard.js                 вкладка "Лидеры"
js/admin.js                       админ-панель (пароль "empc")
js/main.js                        рендер экранов, вкладки, обработка кликов
netlify.toml           конфиг деплоя на Netlify
```

## Локальный запуск

Файлы статические, достаточно любого http-сервера:

```bash
python3 -m http.server 8080
# затем открыть http://localhost:8080
```

Без настройки Firebase игра полностью играбельна: экран входа сам
покажет "облако не настроено" и предложит кнопку "Играть без
аккаунта" — история, инвентарь, магазин, кейсы, доктор и казино
работают без каких-либо внешних сервисов.

## Как подключить Firestore (аккаунты, лидеры, аукцион, админка)

1. Зайди на https://console.firebase.google.com/ и создай проект
   (бесплатного тарифа Spark достаточно).
2. **Build → Authentication → Get started → Sign-in method** —
   включи провайдер **Email/Password**.
3. **Build → Firestore Database → Create database** — выбери любой
   регион, режим (production/test) не важен, правила зададим сами
   на следующем шаге.
4. **Firestore Database → Rules** — вставь и опубликуй:

   ```
   rules_version = '2';
   service cloud.firestore {
     match /databases/{database}/documents {
       match /users/{uid} {
         allow read: if true;
         allow write: if request.auth != null;
       }
       match /auction/{listingId} {
         allow read: if true;
         allow write: if request.auth != null;
       }
     }
   }
   ```

5. **⚙ Project settings → General → Your apps** — нажми "</>" (Web),
   зарегистрируй приложение (галку Firebase Hosting можно не ставить)
   и скопируй объект `firebaseConfig`.
6. Вставь скопированные значения в `js/firebase-config.js` вместо
   заглушек `'ВСТАВЬ_СЮДА'`.
7. Задеплой сайт (или обнови локально) — экран входа сам покажет
   форму регистрации/входа вместо сообщения "облако не настроено".

### Важно про безопасность

Это простая клиентская интеграция без собственного сервера
(Cloud Functions), поэтому:

- Правила Firestore выше разрешают **любому залогиненному**
  пользователю писать в чужие документы — это нужно, чтобы аукцион
  (перевод денег между двумя игроками) и админ-панель вообще могли
  работать без бэкенда.
- Пароль `empc` в админ-панели — это защита от случайных заходов на
  клиенте, **не криптографическая защита**. Технически залогиненный
  пользователь мог бы через консоль браузера напрямую отредактировать
  Firestore и дописать себе денег, минуя админку.
- Для игры с друзьями/для себя это нормальный компромисс. Если нужна
  версия для публичного/конкурентного использования — стоит перенести
  проверку админ-действий и аукционных транзакций на Cloud Functions
  (server-side), чтобы обычные пользователи не имели прямой записи в
  чужие документы.

### Модель данных

- `users/{uid}` — постоянный кошелёк и инвентарь игрока (деньги,
  предметы, чистая стоимость, уровень). Переживает рестарт "жизни"
  (новый случайный персонаж) — это твой постоянный аккаунт, а история
  событий и характеристики (здоровье/энергия/черты) живут только в
  рамках одной партии в браузере.
- `auction/{listingId}` — лоты аукциона (кто продаёт, что, за сколько).

## Деплой на Netlify

1. Залить репозиторий на GitHub (или загрузить папку целиком через
   Netlify Drop — https://app.netlify.com/drop).
2. В Netlify: **Add new site → Import an existing project**, выбрать
   репозиторий.
3. Build command оставить пустым, Publish directory — `.` (корень).
   Файл `netlify.toml` уже задаёт эти настройки автоматически.
4. Deploy site — через минуту сайт будет доступен по ссылке `*.netlify.app`.
5. (Опционально) В Firebase Console → Authentication → Settings →
   Authorized domains добавь домен своего Netlify-сайта — иначе вход
   через email/пароль будет работать только на `localhost`.
