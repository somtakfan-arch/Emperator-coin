## Как собрать

```
cd video/engine
node render.js all ../build          # все серии
node render.js 3 ../build            # одна серия
node render.js all ../preview --preview   # кадры для быстрой проверки
```

- `engine.js` — персонажи, фоны, шаблоны сцен, плашки и субтитры
- `episodes.js` — сценарий: сцены, реплики, субтитры (`*слово*` подсвечивается жёлтым)
- `audio.py` — музыка по настроению сцены и звуковые эффекты
- `tts.py` — озвучка через [Piper](https://github.com/rhasspy/piper): `pip install piper-tts`, голоса `ru_RU-{dmitri,ruslan,denis,irina}-medium.onnx` (+ `.onnx.json`) из `rhasspy/piper-voices` положить в `engine/voices/` или указать путь в `PIPER_VOICES`
- `player.html` — открывается в браузере: `player.html?ep=4&t=12` показывает кадр
