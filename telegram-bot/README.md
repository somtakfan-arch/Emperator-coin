# Emperator Casino — Telegram Bot

Развлекательный казино-бот для Telegram на **Python + aiogram 3**. Валюта —
виртуальные фишки (1 фишка = 1 Telegram Star при покупке), **без вывода
и обмена обратно на деньги**. Это принципиальное архитектурное решение: как
только выигрыш можно обналичить, сервис становится реальным азартным бизнесом
и требует лицензии на игорную деятельность почти в любой юрисдикции. Модель
здесь — «social casino» (как Slotomania и подобные): платный вход, бесплатный
ежедневный бонус, никакого кэшаута.

## Игры

| Игра | Описание | Множитель выигрыша |
|---|---|---|
| 🪙 Монетка (Coinflip) | Орёл/решка, 50/50 | x1.9 |
| 🎲 Кости (Dice) | Угадай число / чёт-нечет / больше-меньше на нативном `send_dice` | x1.9 – x5 |
| 🎰 Слоты | Нативная анимация Telegram `send_dice(emoji="🎰")`, 3 одинаковых символа — выигрыш | x3 – x20 |
| 🎡 Рулетка | Европейская, одно зеро; цвет/чёт-нечет/половина/зеро | x2 – x35 |
| 🃏 Блэкджек | Классика против дилера (дилер берёт до 17), удвоение ставки | x2, блэкджек x2.5 |

Кости и слоты используют **нативную анимацию Telegram** (`send_dice`) — результат
генерируется на серверах Telegram, а не ботом, что выглядит честнее в глазах
игроков (это не крипто-provably-fair, но исключает подозрения в накрутке на
уровне бота).

## Установка

```bash
cd telegram-bot
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
```

1. Получите токен бота у [@BotFather](https://t.me/BotFather) → `/newbot`.
2. Впишите его в `.env` как `BOT_TOKEN`.
3. Оплата звёздами (Stars) включена по умолчанию у всех ботов — отдельный
   `provider_token` не нужен, платежи идут через `currency="XTR"`.
4. Запуск:

```bash
python bot.py
```

База данных — SQLite (`casino.db`), создаётся автоматически при первом запуске.

## Важные ограничения и дальнейшие шаги для продакшена

- **Юридический дисклеймер и возраст 18+** уже есть в `/start`, но перед
  реальным запуском проконсультируйтесь с юристом по законам вашей и целевых
  юрисдикций (Stars-платежи и «игровые» механики регулируются по-разному).
  Не превращайте фишки в выводимые средства без лицензии.
- Хранилище FSM — `MemoryStorage` (в памяти процесса): состояние партии в
  блэкджек теряется при перезапуске бота. Для продакшена с несколькими
  инстансами используйте `RedisStorage`.
- Нет анти-фрод/лимитов на частоту ставок и минимального возраста игрока —
  добавьте проверку при необходимости (например, подтверждение 18+ в `/start`).
- `ADMIN_IDS` в `.env` зарезервирован для будущих админ-команд (статистика,
  бан, ручная выдача фишек) — сейчас не используется в коде.
