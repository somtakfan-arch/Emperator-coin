Как подключиться

Заходим за минуту — вайтлиста нет, лаунчер обычный, версия — Java Edition.

1

Открой Minecraft

Запусти официальный лаунчер, издание Java Edition, актуальная версия клиента.

2

Мультиплеер → Добавить сервер

В списке серверов нажми «Добавить сервер» и придумай ему любое имя.

3

Введи адрес

В поле адреса впиши bedsmp.pro и заходи — дальше выживай сам.

О сервере

Почему BedSMP

Уже полгода держим сервер живым — без нянек, без защиты территорий и без пощады.

🔥

Полная свобода действий

Гриферство, рейды и ловушки разрешены везде — админы не восстанавливают сожжённое.

⚔️

Выживает сильнейший

Строй союзы, предавай, копи ресурсы — здесь работает только твоя смекалка.

🩸

Только честный скилл

Чит-клиенты, x-ray и дюп-баги банятся жёстко и без разговоров.

🌋

Одна общая карта

Без приватных островов и заявок на территорию — все выживают на одной ванильной карте.

💀

Без нянек и жалоб

Потерял базу — сам виноват. Это не баг, а суть сервера.

⏱️

На проекте уже полгода

Сервер стабильно живёт с запуска и не собирается закрываться.
