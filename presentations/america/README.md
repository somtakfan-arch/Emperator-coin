# Америка — презентация по географии

23 слайда о части света Америка: два материка, рельеф, реки, климат, природные зоны,
население, рекорды и экология.

## Два формата

- **`Америка-география.pptx`** — обычный PowerPoint, 16:9. Переходы между слайдами
  (наплыв слева, на титульном — растворение) и анимации появления: заголовок вылетает
  снизу, остальные блоки проявляются каскадом — 387 эффектов на 23 слайда. Плюс заметки
  для докладчика. Анимации и переходы видны в режиме показа (клавиша F5), в режиме
  редактирования они не проигрываются.
- **`index.html`** — веб-версия: слайд жёстко держит формат 16:9 на ПК, с анимацией
  появления текста, отрисовкой карты и плавными переходами.

Управление веб-версией: стрелки `←` / `→`, пробел, свайп на телефоне, точки справа,
`F` или кнопка ⛶ — полный экран.

## Что внутри

- `index.html` — вся веб-презентация: разметка, стили и скрипт навигации.
- `Америка-география.pptx` — версия для PowerPoint (23 слайда).
- `img/` — 20 фотографий с Wikimedia Commons (свободные лицензии / общественное достояние),
  приведены к ширине 1800 px, с повышенной резкостью и яркостью.
- `img/credits.json` — файл, автор и лицензия каждого снимка.

## Карта

Контуры материков на слайде 3 построены по данным Natural Earth (масштаб 110 м)
и спроецированы в равновеликую проекцию Equal Earth — площади передаются без
искажений, в отличие от привычной проекции Меркатора. Путь SVG сгенерирован
из GeoJSON, координаты меток соответствуют реальным координатам объектов.
