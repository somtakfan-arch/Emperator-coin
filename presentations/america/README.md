# Америка — презентация по географии

23 слайда о части света Америка: два материка, рельеф, реки, климат, природные зоны,
население, рекорды и экология.

## Как открыть

Открыть `index.html` в браузере (файл самодостаточный, фотографии лежат в `img/`).

Управление: стрелки `←` / `→`, пробел, свайп на телефоне, точки справа, `F` — полный экран.

## Что внутри

- `index.html` — вся презентация: разметка, стили и скрипт навигации.
- `img/` — 20 фотографий с Wikimedia Commons (свободные лицензии / общественное достояние).
- `img/credits.json` — файл, автор и лицензия каждого снимка.

## Карта

Контуры материков на слайде 3 построены по данным Natural Earth (масштаб 110 м)
и спроецированы в равновеликую проекцию Equal Earth — площади передаются без
искажений, в отличие от привычной проекции Меркатора. Путь SVG сгенерирован
из GeoJSON, координаты меток соответствуют реальным координатам объектов.
