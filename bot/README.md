# 🛡 Bed Protector

Телеграм-бот, который держит оборону чата: капча на входе, антифлуд, антиспам,
антирейд и тревога при массовых банах от «взбесившегося» админа.

## Быстрый старт

```bash
python3 -m venv .venv
.venv/bin/pip install -r bot/requirements.txt

cp bot/.env.example bot/.env
# впиши в bot/.env свежий токен от @BotFather и свой ID в OWNER_IDS
.venv/bin/python bot/run.py
```

Дальше в Telegram:

1. Добавь бота в группу.
2. Выдай права администратора: **удаление сообщений**, **блокировка участников**,
   **приглашение по ссылке**. Без них бот бесполезен.
3. В @BotFather: `/setprivacy` → **Disable** — иначе бот не видит обычные сообщения
   и антиспам работать не будет.
4. В чате набери `/status` — бот покажет, каких прав ему не хватает.

> ⚠️ Токен — это пароль от бота. Не коммить его в git, не пересылай в чатах.
> Утёк — сразу `/revoke` в @BotFather.

## Что делает автоматически

| Модуль | Что ловит | Реакция |
|---|---|---|
| Капча | ботов и «одноразовые» аккаунты | мут до решения примера, кик по таймауту |
| Антифлуд | N сообщений за M секунд | удаление + мут/кик/бан |
| Антиспам | ссылки и инвайты от новичков, пересылы из каналов, стоп-слова, капс, эмодзи-флуд, невидимые символы, повторы, массовые упоминания | удаление + наказание по сумме «очков» |
| Антирейд | всплеск входов | карантин чата: новички молчат до одобрения кнопкой |
| Антиснос | один админ выносит людей пачкой | тревога владельцу, опционально снятие прав |
| Варны | накопленные нарушения | эскалация до бана |

Логика «новичка» — ключевая: жёсткие фильтры применяются к тем, кто недавно вошёл
и написал мало сообщений (`new_user_messages`, `new_user_hours`). Старожилы и
`/trust`-участники живут свободно, поэтому ложных срабатываний почти нет.

## Команды

```
/status  /settings  /set ключ значение
/warn  /unwarn  /warns
/mute [мин]  /unmute  /ban [мин]  /unban  /kick
/trust  /untrust
/lock [мин]  /unlock
/stats [часов]  /id  /help
```

Все команды модерации работают **ответом на сообщение** нарушителя
(`/ban`, `/unban` понимают ещё и числовой ID).

## Настройка под свой чат

У каждого чата свои настройки, они живут в SQLite и меняются на лету:

```
/set captcha off              # выключить капчу
/set spam_threshold 3         # строже фильтр (по умолчанию 4)
/set flood_messages 5         # флуд = 5 сообщений за flood_seconds
/set spam_action ban          # вместо мута — бан
/set raid_joins 4             # рейд = 4 входа за raid_seconds
/set antinuke_demote on       # снимать права у админа при массовых банах
/set log_chat_id -1001234567  # писать журнал модерации в отдельный чат
```

Полный список с описаниями — `/settings`.

### Если ловит лишнее

- подними `spam_threshold` (5–6) — фильтр станет мягче;
- `/set block_links_for_new off` — если у вас принято кидать ссылки сразу;
- `/trust` ответом на сообщение — снять ограничения с конкретного человека;
- стоп-слова правятся в `SPAM_PHRASES` в `protector/heuristics.py`.

### Если пролезает спам

- `spam_threshold 3`, `spam_action ban`, `captcha_timeout 60`;
- `/lock 30` — карантин на время атаки: каждый новичок ждёт одобрения кнопкой;
- `new_user_messages 15`, `new_user_hours 72` — дольше держать новичков под надзором.

## Автозапуск (systemd)

```ini
# /etc/systemd/system/bed-protector.service
[Unit]
Description=Bed Protector Telegram bot
After=network-online.target

[Service]
WorkingDirectory=/opt/Emperator-coin
ExecStart=/opt/Emperator-coin/.venv/bin/python bot/run.py
Restart=always
RestartSec=5
EnvironmentFile=/opt/Emperator-coin/bot/.env

[Install]
WantedBy=multi-user.target
```

```bash
sudo systemctl enable --now bed-protector
journalctl -u bed-protector -f
```

## Структура

```
bot/
├── run.py                     точка входа, polling
├── protector/
│   ├── config.py              .env + настройки чата и их валидация
│   ├── storage.py             SQLite: настройки, участники, варны, журнал
│   ├── heuristics.py          чистые эвристики антиспама (покрыты тестами)
│   ├── runtime.py             скользящие окна: флуд, рейд, дубли, карантин
│   ├── moderation.py          мут/бан/кик/удаление + проверка прав
│   ├── captcha.py             капча и таймауты
│   ├── guard.py               общий контекст: настройки, журнал, оповещения
│   └── handlers/              команды, кнопки, вход участников, сообщения
└── tests/                     python -m unittest discover -s bot/tests -p "test_*.py"
```

## Ограничения

- Бот защищает **чат**. Аккаунт человека Telegram-бот защитить не может —
  см. [../docs/ACCOUNT_PROTECTION.md](../docs/ACCOUNT_PROTECTION.md).
- Снять права у админа бот может только у того, кого сам назначил, — Bot API так
  устроен. Поэтому по умолчанию `antinuke_demote` выключен, а тревога уходит владельцу.
- Счётчики флуда и карантин живут в памяти: после рестарта окна обнуляются
  (настройки, варны и журнал — в БД и сохраняются).
