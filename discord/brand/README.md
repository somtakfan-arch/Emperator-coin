# Айдентика Emperium

Аватарки семьи. Всё нарисовано вектором: буква и корона — контуры, без шрифтовых зависимостей,
поэтому масштабируются без потерь.

| Файл | Что это |
| --- | --- |
| `emperium-A-mark` | Монограмма с короной, матовое серебро. Основной вариант |
| `emperium-A2-mark-text` | То же с подписью EMPERIUM под линией |
| `emperium-A3-metal` | Монограмма с металлическим бликом |
| `emperium-B-signet` | Сигнет: кольцо, разорванное короной, подпись по дуге |
| `emperium-C-crest` | Герб-щит с монограммой |
| `emperium-D-laurel` | Лавровый венок, золото |
| `emperium-E-geometric` | Предельный минимализм: гротеск без засечек |

PNG — 1024×1024, подходит для иконки сервера, аватарки и значка роли.
SVG — исходники, из них можно собрать любой размер.

## Пересборка

```bash
node build.js                       # генерирует SVG и HTML
# рендер PNG (Chromium): см. команду в истории или любой конвертер SVG -> PNG
```

Цвета берутся из палитры семьи: белый `#FFFFFF` как основной, золото `#D9C08A` для акцентов.
