# Финальная айдентика Emperium — вариант D

Лавровый венок, корона и монограмма E. Золото `#D9C08A` на графите, палитра семьи — белый и золото.

| Файл | Куда |
| --- | --- |
| `emperium-D-icon-1024.png` | Иконка сервера Discord, аватарка |
| `emperium-D-icon-512.png` | Запасной размер, аватарки форумов |
| `emperium-D-icon-256.png` | Мелкие места, превью |
| `emperium-D-role-64.png` | Значок роли в Discord (лимит 256 КБ — тут 4 КБ) |
| `emperium-D-icon-transparent.png` | Без фона: накладывать на любой цвет |
| `emperium-D-light.png` | Тёмное золото на слоновой кости — для форума и документов |
| `emperium-D-lockup.png` | Знак + название в строку, без фона — шапки и подписи |
| `emperium-D-banner.png` | Баннер 1920×1080: приглашение, шапка сервера |
| `emperium-D-banner-960.png` | Тот же баннер под лимиты Discord |

SVG рядом — исходники, из них собирается любой размер без потери качества.
`build-d.js` пересобирает весь комплект.
