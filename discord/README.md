# Discord-сервер семьи Emperium (RMRP)

Разворачивает готовый сервер криминальной семьи **Emperium** под GTA 5 RMRP: 13 ролей, 8 категорий, 39 каналов, права доступа и опубликованные правила. Плюс бот: заявки на вступление, сборы, отчёты об активности, ранги и дисциплина.

Структура учитывает правила проекта: категория для куратора с правами администратора (п. 3.11), контроль активности раз в 3 дня (п. 1.3), каналы формы и цвета (п. 3.3–3.4), союзный канал внутри одного сервера (п. 5.10).

- **Цвет семьи:** белый `#FFFFFF` (RGB 255-255-255), стиль old money
- **Прикрытие:** легальная торговля оружием
- **Ранги:** 1 Пустой · 2 Шестёрка · 3 Барыга · 4 Гонец · 5 Ствольщик · 6 Оружейник · 7 Смотрящий · 8 Император

## Что нужно сделать руками (я не могу этого за тебя)

1. **Создать сам сервер** в Discord: `+` слева → «Создать своё» → назвать `Emperium`.
2. **Создать приложение бота:** [discord.com/developers/applications](https://discord.com/developers/applications) → *New Application* → вкладка **Bot** → *Reset Token* → скопировать токен (показывается один раз).
3. В той же вкладке **Bot** включить **SERVER MEMBERS INTENT** — без него бот не увидит новичков.
4. **Пригласить бота** по ссылке (подставь свой Application ID со вкладки *General Information*):
   ```
   https://discord.com/api/oauth2/authorize?client_id=ТВОЙ_CLIENT_ID&permissions=8&scope=bot%20applications.commands
   ```
5. **Поднять роль бота наверх:** Настройки сервера → Роли → перетащить роль бота выше всех остальных. Иначе он не сможет создавать роли и менять ники.

## Запуск без компьютера, с телефона

В репозитории лежит workflow `.github/workflows/discord-setup.yml` — он разворачивает сервер прямо из браузера.

1. GitHub → репозиторий → **Settings → Secrets and variables → Actions → New repository secret**. Добавь три секрета: `DISCORD_TOKEN`, `DISCORD_CLIENT_ID`, `DISCORD_GUILD_ID`.
2. Вкладка **Actions** → слева «Развернуть Discord-сервер Emperium» → **Run workflow**.
3. Галочка `dry_run` показывает план и ничего не меняет; без неё структура разворачивается на сервере.

Токен хранится в секретах GitHub и в логи не попадает. Бота этот способ не запускает — он только строит структуру; для кнопок и команд нужен хостинг (см. ниже).

## Запуск с компьютера

```bash
cd discord
cp .env.example .env      # вписать токен, client id и id сервера
npm install
npm run setup:dry         # показать план, ничего не меняя
npm run setup             # развернуть структуру на сервере
npm start                 # запустить бота (кнопки и команды)
```

ID сервера: настройки Discord → Расширенные → включить «Режим разработчика», затем ПКМ по серверу → «Копировать ID сервера».

`npm run setup` можно запускать сколько угодно раз: недостающее создаётся, существующее подгоняется под конфиг, документы повторно не публикуются.

## Команды бота

| Команда | Кто может | Что делает |
| --- | --- | --- |
| `/setup` | администратор | Развернуть или обновить структуру сервера |
| `/panel` | руководство | Переопубликовать кнопку заявки |
| `/sbor тип время` | все | Сбор с отметками «буду / опоздаю / не смогу» и пингом состава |
| `/aktiv что` | все | Отчёт об активности, сбрасывает таймер неактива |
| `/sostav` | все | Обновить список состава по рангам в `#состав` |
| `/rank @кто ранг` | руководство | Выдать ранг: снимает старую роль, ставит новую |
| `/nick @кто имя статик` | руководство | Ник в формате `Имя Фамилия | 000-000` |
| `/warn @кто причина` | руководство | Предупреждение или выговор с учётом в досье |
| `/unwarn @кто номер` | руководство | Снять запись |
| `/dossier @кто` | все | Досье: ранг, стаж, предупреждения |
| `/ally @кто` | руководство | Выдать или снять роль союзника |
| `/info` | все | Цвет, прикрытие, ранги |

Приём в семью: гость жмёт **📥 Подать заявку** в `#заявка-на-вступление`, заполняет анкету, она падает в `#архив-заявок` с кнопками. По кнопке «Принять» бот выдаёт ранг 1, снимает роль гостя, ставит ник и пишет приветствие в общий чат.

Раз в 6 часов бот проверяет дату последнего отчёта и пингует Смотрящего, если активности не было двое суток — чтобы семья не улетела в неактив на третьи.

## Хостинг 24/7

Бот держит постоянное подключение к Discord, поэтому «бесплатные веб-сервисы, засыпающие без запросов» (Render Free, Vercel) не подходят.

Что реально работает:

- **Бесплатные хостинги ботов** (bot-hosting.net, Sparked Host free tier и подобные): заливаешь папку, указываешь `node src/bot.js`, переменные окружения — в панели. Ноль денег, но возможны перезапуски.
- **Fly.io** — в репозитории лежит `fly.toml` и `Dockerfile`:
  ```bash
  fly launch --no-deploy
  fly secrets set DISCORD_TOKEN=... DISCORD_CLIENT_ID=... DISCORD_GUILD_ID=...
  fly volumes create emperium_data --size 1
  fly deploy
  ```
- **Railway / любой VPS** — тот же `Dockerfile`, либо просто `npm install && npm start` под `pm2`.
- **Свой компьютер** — работает, пока он включён.

**Важно про данные.** Заявки, выговоры и отчёты лежат в `data/store.json`. На хостингах без постоянного диска файл обнуляется при перезапуске — подключи volume и укажи `DATA_FILE=/data/store.json`. Структура сервера, роли и каналы от этого не зависят: они живут в самом Discord.

Если хостинга нет вообще — разверни структуру одним запуском `npm run setup` и пользуйся сервером без бота. Работать не будут только кнопки и слэш-команды; на этот случай в `#заявка-на-вступление` опубликован текстовый шаблон анкеты.

## Как менять структуру

Всё описано в `config/server.json` — роли, категории, каналы, права. Меняешь и запускаешь `npm run setup` заново.

Пресеты доступа:

| Пресет | Кто видит | Кто пишет |
| --- | --- | --- |
| `public-read` | все | руководство |
| `guest` | все | все |
| `members` | состав + куратор | они же |
| `members-read` | состав | руководство |
| `allies` | состав + союзники | они же |
| `staff` | Оружейник и выше | они же |
| `kurator` | Смотрящий, Император, куратор | они же |

`npm test` прогоняет проверку прав без подключения к Discord: не закрыт ли лишнего, не открыт ли приватный канал, нет ли дублей оверрайтов.
