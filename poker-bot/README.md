# Emperator Poker — Telegram-бот + мини-апп

Холдем против 5 ботов или живых людей. Фишки покупаются за звёзды Telegram.
**Вывода нет:** фишки — игровая валюта, на них играют, их выигрывают, но обменять обратно нельзя.

## Что внутри

- **Бот** (`/start`, кнопка «Покер» в меню, `/paysupport`, `/terms`, для админов `/stats` и `/refund <id платежа>`).
- **Мини-апп:** лобби, столы против ботов (1 на 1 или на 6), турниры, создание своего турнира, кошелёк, профиль с топом.
- **Оплата звёздами:** 4 пакета фишек, зачисление после `successful_payment`, повторный платёж не зачислится дважды.
- **Турниры:** свои (2 / 3 / 6 / 18 / 60 игроков, закрытые по ссылке, старт «когда соберутся» или по времени)
  и **Большой турнир** — каждый день в 00:00 по Москве. Столы по 6 с автобалансировкой, рост блайндов,
  призы 60/30/10 (на 18+ игроков — топ-5), рейтинг Эло.
- **Честность:** колода тасуется криптостойко, карты соперников не уходят на телефон, все ходы проверяет сервер.
- **Если сервер перезапустится:** фишки со столов против ботов и взносы незаконченных турниров возвращаются автоматически.

## Запуск у себя (без Telegram)

```bash
cd poker-bot
npm install
npm run dev          # http://localhost:3000/?dev=1  — вход тестовым игроком 1
npm test             # интеграционные тесты
```

В режиме `DEV=1` покупка фишек срабатывает сразу, без оплаты.

## Запуск по-настоящему

Нужен сервер с Node.js 22+, постоянным диском и HTTPS. Проще всего — **Railway** (настраивается с телефона, ~5$/мес).

1. **Бот:** в @BotFather → `/newbot` → сохрани токен.
2. **Railway:** New Project → Deploy from GitHub → этот репозиторий.
   - Settings → Root Directory: `poker-bot`
   - Settings → Networking → Generate Domain → получишь `https://что-то.up.railway.app`
   - Добавь Volume, путь `/data`
   - Variables:
     - `BOT_TOKEN` — токен из BotFather
     - `WEBAPP_URL` — домен из шага выше, со слешем на конце: `https://что-то.up.railway.app/`
     - `DATA_DIR` = `/data`
     - `ADMIN_IDS` — твой Telegram id (узнать: @userinfobot)
3. Готово: напиши боту `/start`. Кнопка «Покер» в меню настраивается сама.

Запускать нужно **ровно один экземпляр** сервера — игры идут в его памяти.

## Настройки (переменные окружения)

| Переменная | По умолчанию | Что это |
|---|---|---|
| `START_CHIPS` | 0 | фишки новому игроку |
| `DAILY_BONUS` | 0 | ежедневный бонус (0 — выключен) |
| `PACK1_STARS` / `PACK1_CHIPS` … `PACK4_…` | 50/5 000, 100/12 000, 200/30 000, 500/100 000 | пакеты фишек |
| `BIG_HOUR_UTC` | 21 | час старта Большого турнира по UTC (21 = 00:00 МСК) |
| `BIG_BUYIN` / `BIG_MAX` / `BIG_MIN_RATING` | 1000 / 60 / 0 | взнос, мест, мин. рейтинг Большого |
| `BIG_BLIND_MIN` | 6 | минут на уровень блайндов в Большом |
| `TURN_SECONDS` | 25 | время на ход |

## Файлы

- `server/index.js` — HTTP + WebSocket, хаб игроков, расписание
- `server/telegram.js` — Bot API, проверка подписи мини-аппа, звёзды
- `server/db.js` — SQLite (встроен в Node), журнал всех движений фишек
- `server/game/table.js` — стол: ход живого игрока, паузы, рассылка
- `server/game/botroom.js` — стол против ботов
- `server/game/tournament.js` — турниры, балансировка, призы, Эло
- `public/` — мини-апп
- `core/` — движок покера и боты (см. `core/README.md`)
