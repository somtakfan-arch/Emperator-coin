# Покерные боты (Техасский Холдем, No-Limit)

Чистый JS, без зависимостей: работает в браузере (`<script type="module">`) и в Node.

## Как думают (одинаково у всех пятерых)

1. **Читают руки по Байесу.** На каждого соперника — вес для каждой из 1326 комбинаций.
   После каждого его действия веса пересчитываются: «с какими руками он бы так сделал?».
   Вероятности берутся из его реальных частот в этой ситуации (рейз / колл / фолд)
   и из доли блефа, пойманной на вскрытиях.
2. **Решают по EV.** Для чека, колла, фолда и каждого размера ставки считается матожидание:
   фолд-эквити × банк + эквити против диапазона, который продолжит.
3. **Смешанные стратегии.** Близкие по EV действия выбираются случайно — по паттерну не прочитать.
4. **Префлоп:** диапазоны по позициям, 3бет/4бет-блефы одномастными тузами и коннекторами,
   защита BB от ширины опенера, пуш/фолд на коротком стеке, отдельная логика хедз-апа.

## Характеры

| Бот | Стиль |
|---|---|
| **Скала** | аккуратный: узкие диапазоны, минимум риска, точечные блефы |
| **Акула** | GTO-баланс: много сайзингов, сильное смешивание, почти не подстраивается — её сложно эксплуатировать |
| **Маньяк** | борзый: широкие диапазоны, овербеты, много 3бет/4бет-блефов |
| **Охотник** | эксплойтер: учит соперника за пару десятков раздач и бьёт по его дырам |
| **Хамелеон** | меняет передачу каждые 15–40 раздач (тайт / луз / ловушки) — статистика на него устаревает |

## Проверка силы

Дубликат-дуэли один на один (одинаковые колоды, боты меняются местами, везение сокращается),
2000×2 раздач. Все 35 матчей в плюсе:

| | v1 (старые боты) | Нит | Колл-станция | Агрессор |
|---|---|---|---|---|
| Элита | от +3 до +123 бб/100 | ≈ +60 бб/100 | +800…+1700 бб/100 | ≈ +1100 бб/100 |

```bash
node duel.js Охотник v1:Маньяк 3000   # дуэль
node duel.js Акула station 1000       # против эксплойт-бота
```

Честно: это сильно и для человека очень неудобно, но не уровень Pluribus/Libratus —
те обучались на суперкомпьютерах миллиардами раздач.

## Файлы

- `brain.js` — мозг: байесовские диапазоны, EV, префлоп-стратегия
- `bots.js` — 5 характеров
- `strength.js` — сила всех 1326 комбинаций на доске
- `model.js` — частоты соперников
- `cards.js` — колода, оценка рук, префлоп-эквити 169 рук
- `engine.js` — стол: блайнды, ставки, сайд-поты, шоудаун
- `benchmarks.js` — спарринг: старые боты v1 и эксплойт-боты
- `equity.js` — простое эквити (используют v1)
- `sim.js` — прогон стола, `duel.js` — дубликат-дуэль

## Запуск

```bash
cd poker-bot/core
node sim.js 2000            # 2000 раздач, итоговая таблица
node sim.js 300 --log       # с логом первых раздач
node sim.js 5000 --seed 42  # воспроизводимый прогон
node sim.js 3000 --lineup Акула,Охотник,v1:Маньяк,station  # свой состав
```

## Как подключить

```js
import { Table } from './engine.js';
import { createBots } from './bots.js';

const players = createBots().map((bot, i) => {
  bot.id = i;
  return { id: i, name: bot.name, stack: 1000, bot };
});
const table = new Table({ players, smallBlind: 5, bigBlind: 10, onEvent: (e) => console.log(e) });
table.playHand();
```

Живой игрок — любой объект с `act(state)`, который возвращает
`{ type: 'fold' | 'check' | 'call' }` или `{ type: 'raise', to: 120 }`.
