# Новая мини-игра

Все 12 игр живут в одном файле `games/2-4-player-games/index.html` (~4000
строк), разбитом на 14 пронумерованных секций. Карта секций:

```
grep -n '^ \* [0-9]*\.' games/2-4-player-games/index.html
```

| № | Секция | Зачем нужна при добавлении игры |
|---|---|---|
| 1 | `CONFIG` | сюда кладётся блок баланса новой игры |
| 3 | Утилиты | `clamp`, `rr`, `TAU` и прочее |
| 4 | `Sound` | синтезатор WebAudio, без файлов |
| 5 | `FX` | тряска, всплывающие очки, конфетти, трейлы |
| 6 | `GAME` | размеры холста, `GAME.scale`, `GAME.areaTop/areaW/areaH` |
| 7 | `Input` | мультитач по углам + клавиатура |
| 9 | `BaseGame` | базовый класс, от него наследуемся |
| 13 | `drawIcon` | иконка карточки в меню выбора |
| 14 | Главный цикл | вызывает `update(dt)` и `render(ctx)` |

## Контракт игры

Класс наследует `BaseGame` и обязан реализовать:

- `update(dt)` — шаг симуляции, `dt` в секундах, уже ограничен сверху 0.05
- `render(ctx)` — отрисовка кадра
- `onResize()` — пересчёт геометрии под новый размер холста
- `decideBot(i, dt) -> bool` — ИИ для неигрового слота, возвращает «нажата ли кнопка»

Что даёт база:

- `this.scores` — массив на 4 игрока
- `this.state` — `'countdown' | 'playing' | 'roundEnd' | 'matchOver'`
- `computeFrameInput(dt)` → `{ held: bool[4], tap: bool[4] }` — уже сводит
  людей и ботов в один интерфейс; **вводи только через него**
- `tickCountdown(dt)` — вернёт `true`, когда отсчёт закончился
- `tickRoundEnd(dt, onDone)`
- `endRound(winners)` — начисляет очки и переводит в паузу раунда;
  победа в матче и экран победителя обрабатываются автоматически

## Единственная модель управления

У каждого игрока **одна кнопка**. Вся глубина — в том, что означает
удержание и что означает тап. Примеры из существующих игр: удержание =
поворот (танчики, змейки), тап = рывок (сумо), тап = выстрел в нужный
момент (дуэль, пенальти). Не добавляй второй кнопки, джойстика или свайпов —
это сломает раскладку углового мультитача и клавиатурные клавиши
`q / p / z / m`.

## Порядок добавления

1. **Блок баланса в `CONFIG`** (секция 1). Все величины задаются в опорных
   единицах для короткой стороны арены = 700px и умножаются на `GAME.scale`
   в рантайме. Никаких абсолютных пикселей в логике.

2. **Класс игры** — новой пронумерованной секцией после последней мини-игры,
   с таким же баннером-комментарием:

   ```js
   /* ==========================================================================
    * 15. МИНИ-ИГРА 13: НАЗВАНИЕ
    * ========================================================================== */
   class MyGame extends BaseGame { ... }
   ```

   Арена считается от `GAME.areaTop / areaW / areaH` — не от `GAME.h`:
   сверху находится HUD высотой `HUD_H`.

   Тяжёлый статичный фон рисуй один раз в `buildBg()` через `makeLayer()` и
   перерисовывай только в `onResize()`. Рисовать шум и текстуру каждый кадр —
   верный способ уронить fps на телефоне.

3. **Иконка меню** — ветка `else if(kind==='mykey')` в `drawIcon` (секция 13).
   Только canvas-примитивы: внешних картинок в проекте нет принципиально.

4. **Регистрация в `GAME_LIST`** (~строка 766), одной строкой в общем
   выравнивании:

   ```js
   { key:'mykey', name:'НАЗВАНИЕ', tag:'ЖАНР', accent:'#hex',
     desc:'Одна фраза: что делает кнопка и какая цель.', make:()=>new MyGame() },
   ```

   `key` обязан совпадать с веткой в `drawIcon`. `name` и `tag` — заглавными
   по-русски, `desc` — одно предложение в повелительном наклонении, как у
   соседей.

5. **Звук и тактильность.** Дёргай `Sound.*` и `FX.*` на ключевых событиях —
   без них игра ощущается мёртвой на фоне остальных. Обе подсистемы уважают
   флаги `CONFIG.fx.sound` и `CONFIG.fx.vibration`.

## Проверка

```
node --check <(sed -n '/<script>/,/<\/script>/p' games/2-4-player-games/index.html | sed '1d;$d')
python3 .claude/skills/check/check.py
```

Затем открыть `python3 -m http.server 8000` и прокликать: карточка видна в
меню, игра стартует на 2 и на 4 игроках, боты шевелятся, раунд начисляет
очки, матч доходит до экрана победителя.

Бампать `CACHE_VERSION` не нужно: у `games/` нет service worker'а.
