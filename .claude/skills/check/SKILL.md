# Проверка перед пушем

В проекте нет ни сборки, ни тестов, ни линтера — CI просто копирует файлы на
Pages. Поэтому единственный барьер между опечаткой и продакшном — этот скрипт.

```
python3 .claude/skills/check/check.py
```

Код возврата 0 — можно пушить, 1 — есть ошибки. Предупреждения не блокируют,
но их стоит прочитать.

## Что проверяется

1. **Манифесты PWA** (`manifest.json`, `stickman/manifest.json`) — парсятся,
   есть обязательные поля, каждая иконка существует на диске, есть
   maskable-вариант.

2. **PRECACHE_URLS обоих service worker'ов** — каждый URL резолвится в
   реальный файл. Самая дорогая ошибка в проекте: `cache.addAll()` отклоняет
   **весь** промис при первом же 404, и service worker не устанавливается
   вообще ни у кого. Одна опечатка в пути = офлайн-режим лёг у всех.

3. **Синтаксис JS** — `node --check` по всем `.js` и по инлайновым
   `<script>` в HTML, включая четырёхтысячестрочный
   `games/2-4-player-games/index.html`.

4. **Бамп `CACHE_VERSION`** — если относительно `origin/main` изменился хоть
   один закэшированный ассет, а версия кэша осталась прежней, это ошибка:
   обновление не доедет до установивших PWA. См. скилл `bump-sw`.

5. **Деплой** — что каждая папка верхнего уровня упомянута в шаге
   `Prepare site directory` (список копирования поимённый, добавленную папку
   легко забыть), и что текущая ветка есть в `on.push.branches`.

## Как чинить

| Сообщение | Что делать |
|---|---|
| `PRECACHE_URLS ссылается на несуществующий ...` | опечатка в пути или файл переименован/удалён — поправь массив в `sw.js` |
| `CACHE_VERSION остался ...` | подними версию, скилл `bump-sw` |
| `синтаксическая ошибка` | номер строки в сообщении, файл указан до двоеточия |
| `иконка ... не существует` | перегенерируй, скилл `icons` |
| `... не копируется в _site` | добавь путь в `cp -r` в `.github/workflows/deploy-pages.yml` |
| `ветки ... нет в on.push.branches` | добавь ветку в воркфлоу, если хочешь превью-деплой с неё |

## Ручная проверка сверх скрипта

Скрипт не открывает браузер. После правок UI подними сервер и прокликай:

```
python3 -m http.server 8000
```

`file://` не годится — service worker и манифест по нему не работают.
