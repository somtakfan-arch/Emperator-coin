Запусти проверку:

!`node "${CLAUDE_PLUGIN_ROOT}/scripts/check.mjs" ${ARGUMENTS:-.}`

Затем:
1. Сгруппируй найденное по категориям (визуал, композиция, типографика, тексты, анимация, код).
2. Отдельно перечисли то, что автоматическая проверка не ловит: конвейер секций (L04), div-суп (K05),
   отсутствие детали из предметной области, одинаковые карточки. Для этого прочитай сами файлы.
3. Для каждого пункта предложи конкретную замену с учётом темы проекта, а не общий совет.
4. Ничего не меняй в файлах, пока пользователь не скажет. Предложи запустить `/human-web:fix`.
