# Human Web: вёрстка без признаков генерации

Полный список правил с ID лежит в `${CLAUDE_PLUGIN_ROOT}/config/rules.json`. После каждой записи
HTML/CSS/JSX-файла хук `scripts/check.mjs` проверяет его. BLOCK-нарушения нужно исправить сразу,
WARN-замечания учесть, если нет причины оставить (тогда объясни причину в ответе).

Приоритет: прямые слова пользователя → дизайн-система проекта (CLAUDE.md, токены, существующие стили) → эти правила.
Если пользователь сам просит фиолетовый градиент или эмодзи, делай как просят.

## Главное правило: никаких капслок-надписей над секциями

Не ставь над заголовками мелкие надписи заглавными буквами с разрядкой: ВОЗМОЖНОСТИ, ТАРИФЫ,
КАК ЭТО РАБОТАЕТ, О НАС, ОТЗЫВЫ, FEATURES, PRICING. Это самый заметный признак сгенерированной
страницы. Не обходи запрет через `text-transform`, `font-variant: small-caps`, классы `eyebrow` /
`overline` / `kicker` или текст, набранный капсом прямо в разметке. Секцию открывает её заголовок.

## Перед тем как писать код

1. Определи предмет: что за продукт, кто посетитель, какое одно действие он должен сделать.
   Если этого не видно из задачи и репозитория, спроси одним вопросом.
2. Найди в предмете материал для дизайна: цвета, термины, единицы измерения, документы, фактуры
   из его мира. Хотя бы одна деталь на странице должна быть такой, которая есть только у этого проекта.
3. Задай токены в `:root` (4-6 цветов, 2 шрифта с ролями, шкала размеров). Дальше только через них.

## Визуал (V)
- Не используй фиолетово-синие градиенты, градиентный текст, светящиеся blur-пятна, сетку точек на фоне.
- Glassmorphism максимум в одном месте (sticky-навигация).
- 2-3 радиуса с ролями вместо `rounded-2xl` на всём. Тени только у всплывающих слоёв.
- Никаких эмодзи в роли иконок. Одна SVG-система или без иконок.
- Не скатывайся в три «вкусных» пресета: кремовый+засечки+терракота, почти чёрный+неон, белый+фиолетовый градиент.

## Композиция (L)
- Левое выравнивание по умолчанию, центр только для коротких одиночных фраз.
- Hero по высоте контента, не `100vh`. Следующий блок виден в первом экране.
- Не собирай конвейер «hero → логотипы → 3 фичи → шаги → отзывы → тарифы → FAQ → CTA».
  Оставь только секции, которые отвечают на главный вопрос посетителя.
- Никаких выдуманных логотипов клиентов, круглых цифр без источника, бейджа «✨ Новое» над H1.
- Нумерация 01/02/03 только у настоящей последовательности.
- Разный вертикальный ритм: плотно внутри темы, просторно между темами.

## Типографика (T)
- Не ставь Inter / Space Grotesk / Poppins по умолчанию. Подбери пару под тему через Google Fonts.
- Шкала размеров и минимум два веса. Sentence case в заголовках.
- Подзаголовок только если добавляет новую информацию. Капслок-надстрочники запрещены (см. главное правило).

## Тексты (C)
- Запрещены штампы: unlock, elevate, seamless, supercharge, revolutionize, cutting-edge, empower,
  «раскройте потенциал», «бесшовный», «революционный», «инновационный», «на новый уровень», «в один клик».
- Запрещена конструкция «Это не просто X, это Y». Сразу говори Y.
- Без триад «Быстро. Надёжно. Удобно.», без заголовков-вопросов, без восклицаний.
- Тире умеренно: точка или запятая чаще.
- Кнопка называет конкретное действие («Открыть демо-счёт»), а не «Начать» / «Подробнее».
- Никаких выдуманных отзывов, имён, цифр, логотипов. Нет данных: спроси или оставь блок пустым с пометкой TODO для пользователя.
- Никаких lorem ipsum, «Ваша компания», example.com.

## Анимация (M)
- Контент виден сразу после загрузки. Никаких AOS / fade-in-up на каждой секции.
- Hover-эффект только у кликабельного, без подпрыгивания карточек.
- Анимируй конкретные свойства, не `transition-all`. Уважай `prefers-reduced-motion`.
- Без пульсирующих CTA, плавающих картинок и печатающихся заголовков.

## Код (K)
- Семантика: header, nav, main, section, footer, один h1.
- Без комментариев-разделителей `<!-- Hero Section -->`.
- Без стоковых заглушек (unsplash random, picsum, placeholder).
- Без `href="#"`: настоящая ссылка или `<button>`.
- Год в футере не хардкодить.

## Самопроверка перед ответом

Прогони `node "${CLAUDE_PLUGIN_ROOT}/scripts/check.mjs" <папка>` и пройдись глазами:
если закрыть логотип, можно ли угадать, о каком продукте страница? Если нет, ищи, что ещё шаблонного осталось.
