# BedNoTridents

Плагин для **Paper 1.21.11** (BedSMP). Удаляет **трезубцы** отовсюду и снимает **трезубцовые чары**
со всех предметов и книг.

Готовый файл: **`BedNoTridents-1.0.0.jar`** — кинуть в папку `plugins/` и перезапустить сервер.
Работает независимо от BedNoEnchants и BedNoFireworks, можно ставить все три вместе.

---

## Что удаляется

| Где | Как |
|---|---|
| Инвентарь игрока, броня, вторая рука, курсор | при входе, респавне, кликах, открытии/закрытии инвентаря + фоновый проход |
| Эндер-сундук | при входе и в фоновом проходе (у оффлайн-игроков — при следующем входе) |
| Сундуки, бочки, раздатчики, воронки, вагонетки | проход по тайл-энтити всех загруженных чанков + при открытии |
| **Шалкеры, шалкеры в сундуках, шалкеры в шалкерах, бандлы** | рекурсия до 16 уровней вложенности |
| **Утопленники** | трезубец убирается из рук и из дропа |
| Предметы на земле (дроп) | сущность-предмет удаляется |
| **Брошенный трезубец в полёте / воткнутый в землю** | сущность удаляется |
| Рамки, стойки для брони, экипировка любых мобов | обход сущностей чанка |
| Лут из структур и рыбалки | `LootGenerateEvent` — до попадания в сундук |
| Сделки жителей с трезубцем | сделка не появляется у торговца |

## Какие чары снимаются

По умолчанию — только трезубцовые, со **всех** предметов и книг:

| Чара | Название |
|---|---|
| `loyalty` | Верность |
| `riptide` | Тягун |
| `channeling` | Громовержец |
| `impaling` | Пронзатель |

Остальные чары **не трогаются**: книга с Тягуном и Остротой V потеряет Тягун и останется с Остротой V.
Список правится в `config.yml` → `enchantments.list` (можно вписать любые чары Minecraft).
Если поставить `enchantments.all: true` — снимутся вообще все чары, как в BedNoEnchants.
Книга, оставшаяся совсем без чар, превращается в обычную книгу.

## Что запрещается

| Действие | Результат |
|---|---|
| Бросок трезубца | отменяется |
| **Разгон Тягуном (riptide)** | отменяется (правый клик с трезубцем не проходит) |
| Зачарование трезубца на столе | стол не показывает варианты |
| Получение запрещённых чар на столе/наковальне | чары вырезаются из результата |

Всё отключается по отдельности в `config.yml` (секции `remove`, `enchantments`, `block`).

## Команды

| Команда | Что делает |
|---|---|
| `/notridents scan` | немедленная зачистка всех загруженных чанков и игроков |
| `/notridents stats` | удалено трезубцев, снято чар, сущностей, чанков, блокировок |
| `/notridents reload` | перечитать `config.yml` |
| `/notridents toggle` | включить/выключить плагин на лету |

Алиасы: `/bnt`, `/notrident`, `/notrez`. Права: `bednotridents.admin` (по умолчанию — оператор).

## Проверено

Собран и протестирован на настоящем сервере **Paper 1.21.11 (build 132)**:

* трезубец с Верностью III в сундуке → удалён;
* **трезубец в шалкере внутри сундука** → удалён, алмазы рядом целы;
* книга с **Тягуном III и Остротой V** → остался только Острота V;
* меч с **Пронзателем V и Остротой V** → остался только Острота V;
* **утопленник с трезубцем в руке** → рука пустая;
* брошенный трезубец, воткнутый в землю → удалён;
* счётчики: 3 трезубца, 2 снятых чары, 1 сущность;
* повторный `/notridents scan` — 0 изменений, ошибок в логе нет.

> Если в консоли вместо русских букв `?????` — добавь в старт сервера `-Dfile.encoding=UTF-8`.

## Сборка из исходников

```bash
cd plugins/BedNoTridents
mvn clean package
# готовый jar -> target/BedNoTridents-1.0.0.jar
```

Требуется JDK 21 и Maven. Зависимость — `io.papermc.paper:paper-api:1.21.11-R0.1-SNAPSHOT` (provided).
