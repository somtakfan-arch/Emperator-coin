# BedNoEnchants

Плагин для **Paper 1.21.11** (BedSMP). Убирает зачарования с **абсолютно всех** предметов на сервере,
сбрасывает кастомные характеристики оружия и брони до ванильных и не даёт всему этому появиться заново.

Готовый файл: **`BedNoEnchants-1.1.0.jar`** — кинуть в папку `plugins/` и перезапустить сервер.

---

## Что чистится

| Где | Как |
|---|---|
| Инвентарь игрока, броня, вторая рука, курсор | при входе, респавне, кликах, открытии/закрытии инвентаря + фоновый проход |
| Эндер-сундук | при входе и в фоновом проходе (у оффлайн-игроков — при следующем входе) |
| Сундуки, бочки, печи, воронки, раздатчики, книжные полки, стойки для зелий | проход по тайл-энтити всех загруженных чанков + при открытии |
| **Шалкеры-предметы** | содержимое чистится внутри предмета |
| **Шалкеры внутри сундуков, шалкеры внутри шалкеров, бандлы** | рекурсия до 16 уровней вложенности |
| Предметы на земле (дроп) | `ItemSpawnEvent`, дроп игрока, дроп мобов, дроп блоков, подбор |
| Рамки, витрины, стойки для брони | обход сущностей чанка |
| Экипировка мобов (зомби с зачарованным мечом и т.п.) | при спавне и в фоновом проходе |
| Вагонетки/лодки с сундуком, инвентари жителей, сундуки на лошадях/ламах | обход сущностей чанка |
| Лут из структур (бастионы, храмы, крепости, рыбалка) | `LootGenerateEvent` — чары исчезают до появления в сундуке |
| Сделки жителей и странствующих торговцев | `VillagerAcquireTradeEvent` + при покупке |
| Результат наковальни, точила, кузнечного стола, верстака | `PrepareResultEvent` / `PrepareItemCraftEvent` |
| Стол зачарований | зачарование запрещено (`block-enchanting-table`) |
| Воронки и раздатчики, гоняющие вещи между сундуками | `InventoryMoveItemEvent` |
| Выдача через `/give`, `/loot`, `/item`, `/summon` | перепроверка инвентарей через тик после команды |

Зачарованные книги превращаются в обычные (`convert-enchanted-books: true`), убирается и
принудительный «блеск» (`enchantment_glint_override`).

## Ванильные характеристики (`vanilla-gear`)

Помимо чар, с предметов снимается всё, что накручено сверху, — характеристики
возвращаются к **стандартным ванильным**:

* **урон при атаке и скорость атаки**, броня, вязкость брони, отбрасывание,
  скорость передвижения, доп. здоровье — любые `attribute_modifiers`;
* неломаемость, кастомная прочность, накрученная цена на наковальне;
* компоненты `tool` / `weapon` / `piercing_weapon` / `kinetic_weapon` / `attack_range` /
  `swing_animation` / `minimum_attack_charge` / `damage_type` — скорость копания, урон по
  прочности, пробитие щита, дальность удара;
* `blocks_attacks` (кастомные щиты), `equippable` (надеть что угодно куда угодно),
  `glider` (полёт без элитр), `death_protection` (эффект тотема на любом предмете),
  `damage_resistant` (иммунитет к огню);
* `food` / `consumable` / `use_cooldown` / `use_remainder` — кастомные «гэплы» и хилки;
* `can_place_on`, `can_break`, `max_stack_size`, `enchantable`, `repairable`.

Работает через Data Component API Paper: `resetData` возвращает компоненту **то самое
значение, которое у предмета в обычной игре**. Поэтому:

* алмазный меч с уроном 1000 → обычный алмазный меч с обычным уроном;
* обычный алмазный меч **не меняется вообще** (проверено: повторное сканирование
  насчитывает 0 изменений);
* незеритка с +50 брони → обычная незеритка.

Список компонентов настраивается в `config.yml` → `vanilla-gear.components`.
Косметика (`custom_name`, `lore`, `custom_model_data`, `item_model`, `rarity`, `custom_data`)
по умолчанию **не трогается** — иначе поломались бы меню `/shop` и `/ah`.
Если нужно снести и названия — раскомментируй их в списке.

> ⚠️ Кастомные предметы сервера (ломатель брони, удалятель тотемов, топор-глушилка,
> стейк-гепл) держатся как раз на чарах и этих компонентах, так что они тоже станут
> обычными вещами. Если какие-то из них надо сохранить — убери соответствующие строки
> из `vanilla-gear.components` и напиши, добавлю белый список по названию предмета.

## Как это работает

1. **Стартовая зачистка** — при включении плагина проходит по всем загруженным чанкам и игрокам.
2. **События** — любой предмет, который появляется, перемещается или создаётся, чистится на месте.
3. **Фоновый проход** — раз в `sweep.interval-ticks` (по умолчанию 60 секунд) в очередь ставятся все
   загруженные чанки, обрабатываются порциями по `sweep.chunks-per-tick` штук за тик, чтобы не ронять TPS.
4. **При загрузке чанка** — каждый чанк чистится, как только подгружается. Так весь мир, включая
   давно заброшенные базы, очищается по мере того, как игроки туда заходят.

### Важно про то, что сервер не видит

Bukkit API не умеет читать содержимое **выгруженных чанков** и инвентари **оффлайн-игроков** —
их не существует в памяти. Плагин закрывает это иначе:

* выгруженный чанк чистится в момент загрузки (`sweep.on-chunk-load: true`);
* инвентарь и эндер-сундук оффлайн-игрока — в момент его следующего входа.

Так что «пропущенных» зачарованных вещей не остаётся: вещь всё равно попадёт в руки игрока
только через загруженный чанк или через вход на сервер.

## Команды

| Команда | Что делает |
|---|---|
| `/noenchants scan` | немедленная полная зачистка всех загруженных чанков и всех игроков |
| `/noenchants stats` | сколько предметов, контейнеров, чанков и инвентарей очищено |
| `/noenchants reload` | перечитать `config.yml` |
| `/noenchants toggle` | включить/выключить плагин на лету |

Алиасы: `/bne`, `/noench`. Права: `bednoenchants.admin` (по умолчанию — оператор).

## Конфиг

Все настройки — в `plugins/BedNoEnchants/config.yml` с комментариями на русском.
Основное:

```yaml
enabled: true
convert-enchanted-books: true    # зачарованная книга -> обычная книга
block-enchanting-table: true     # запретить зачарование
sweep:
  interval-ticks: 1200           # полный проход раз в 60 секунд
  chunks-per-tick: 10            # мягко для TPS
```

Если нужно оставить исключения (например, админские вещи) — включите `bypass.enabled: true`
и выдайте право `bednoenchants.bypass`. По умолчанию выключено: чистится всё и у всех.

## Сборка из исходников

```bash
cd plugins/BedNoEnchants
mvn clean package
# готовый jar -> target/BedNoEnchants-1.1.0.jar
```

Требуется JDK 21 и Maven. Зависимость — `io.papermc.paper:paper-api:1.21.11-R0.1-SNAPSHOT` (provided).

## Проверено

Плагин собран и протестирован на настоящем сервере **Paper 1.21.11 (build 132)**:

* сундук с зачарованным алмазным мечом → меч чистый;
* меч с +1000 урона, +500% скорости, неломаемостью, прочностью 99999 и Остротой X →
  байт в байт совпадает с обычным алмазным мечом;
* незеритовый нагрудник с +50 брони → обычный нагрудник;
* стейк с сытостью 20 и эффектом тотема → обычный стейк;
* обычный алмазный меч в том же сундуке остался нетронутым, повторный `/noenchants scan`
  насчитал 0 изменений (лишних записей в инвентари нет);
* шалкер **внутри сундука** с зачарованной книгой (Починка) → внутри обычная книга;
* дропнутая кирка с Эффективностью V → чистая сразу после появления;
* зомби, заспавненный с зачарованным железным мечом → меч чистый;
* ошибок и исключений в логе нет.

> Если в консоли вместо русских букв `?????` — у JVM не UTF-8 локаль.
> Добавьте в старт сервера `-Dfile.encoding=UTF-8`. На сообщения в игре это не влияет.

## Производительность

* Проверка предмета без чар — один вызов `getEnchantments()`, мусора почти нет.
* Фоновый проход ограничен бюджетом чанков за тик; при 20 игроках нагрузка незаметна.
* Если всё-таки тяжело: уменьшите `sweep.chunks-per-tick`, увеличьте `sweep.interval-ticks`
  или выключите `hook-hoppers`.
