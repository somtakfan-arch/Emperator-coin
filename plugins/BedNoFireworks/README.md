# BedNoFireworks

Плагин для **Paper 1.21.11** (BedSMP). Удаляет фейерверки **отовсюду** и не даёт ими пользоваться.

Готовый файл: **`BedNoFireworks-1.0.0.jar`** — кинуть в папку `plugins/` и перезапустить сервер.
Работает независимо от BedNoEnchants, можно ставить оба вместе.

---

## Что удаляется

Ракеты (`firework_rocket`) и звёздочки (`firework_star`):

| Где | Как |
|---|---|
| Инвентарь игрока, броня, вторая рука, курсор | при входе, респавне, кликах, открытии/закрытии инвентаря + фоновый проход |
| Эндер-сундук | при входе и в фоновом проходе (у оффлайн-игроков — при следующем входе) |
| Сундуки, бочки, раздатчики, воронки, вагонетки | проход по тайл-энтити всех загруженных чанков + при открытии |
| **Шалкеры-предметы, шалкеры в сундуках, шалкеры в шалкерах, бандлы** | рекурсия до 16 уровней вложенности |
| **Заряженные арбалеты** | ракета выгружается из арбалета |
| Предметы на земле (дроп) | удаляется сама сущность-предмет |
| Рамки, стойки для брони, экипировка мобов | обход сущностей чанка |
| **Запущенные фейерверки в воздухе** | сущность удаляется при появлении |
| Лут из структур и рыбалки | `LootGenerateEvent` — до попадания в сундук |
| Сделки жителей с фейерверками | сделка не появляется у торговца |

## Что запрещается

| Действие | Результат |
|---|---|
| Использовать ракету в руке | отменяется, в actionbar — «На BedSMP фейерверки отключены» |
| **Разгон на элитрах ракетой** | отменяется, ракета не тратится |
| Выстрел фейерверком из арбалета | отменяется, ракета выгружается |
| Раздатчик с фейерверком | не срабатывает |
| Крафт ракет и звёздочек | рецепты удаляются с сервера (`firework_rocket`, `firework_star`, `firework_star_fade`) |

Всё перечисленное отключается по отдельности в `config.yml` (секции `remove` и `block`).

## Как это работает

1. **Стартовая зачистка** — при включении проходит по всем загруженным чанкам и игрокам.
2. **События** — фейерверк удаляется в момент появления, подбора, передачи, выпадения.
3. **Фоновый проход** — раз в 60 секунд очередь из всех загруженных чанков, порциями
   по 10 чанков за тик, чтобы не ронять TPS.
4. **При загрузке чанка** — весь мир очищается по мере того, как игроки туда заходят.

Выгруженные чанки и инвентари оффлайн-игроков API не видит: они чистятся ровно в момент
загрузки чанка и входа игрока.

## Команды

| Команда | Что делает |
|---|---|
| `/nofireworks scan` | немедленная зачистка всех загруженных чанков и игроков |
| `/nofireworks stats` | сколько удалено предметов, сущностей, чанков, заблокировано применений |
| `/nofireworks reload` | перечитать `config.yml` |
| `/nofireworks toggle` | включить/выключить плагин на лету |

Алиасы: `/bnf`, `/nofw`, `/nofire`. Права: `bednofireworks.admin` (по умолчанию — оператор).

## Проверено

Собран и протестирован на настоящем сервере **Paper 1.21.11 (build 132)**:

* сундук с 64 ракетами и 12 звёздочками → пусто;
* **шалкер внутри сундука** с 32 ракетами → внутри остались только алмазы;
* **заряженный арбалет** с ракетой → арбалет пустой;
* запущенный фейерверк в воздухе → удалён;
* всего насчитано ровно 109 удалённых фейерверков (64 + 12 + 32 + 1);
* алмазы в том же сундуке не тронуты, повторный `/nofireworks scan` — 0 удалений;
* рецепты фейерверков отключены при старте, ошибок в логе нет.

> Если в консоли вместо русских букв `?????` — добавь в старт сервера `-Dfile.encoding=UTF-8`.
> На сообщения в игре это не влияет.

## Сборка из исходников

```bash
cd plugins/BedNoFireworks
mvn clean package
# готовый jar -> target/BedNoFireworks-1.0.0.jar
```

Требуется JDK 21 и Maven. Зависимость — `io.papermc.paper:paper-api:1.21.11-R0.1-SNAPSHOT` (provided).
