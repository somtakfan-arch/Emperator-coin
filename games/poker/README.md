# Покерные боты (Техасский Холдем, No-Limit)

Чистый JS, без зависимостей: работает в браузере (`<script type="module">`) и в Node.

## Боты

| Бот | Стиль | Как думает |
|---|---|---|
| **Скала** | аккуратный (тайт-пассив) | ~12% рук, блефует почти никогда, верит чужим ставкам, сбрасывает без сожаления |
| **Акула** | сбалансированный профи (TAG) | баланс вэлью/блефа, на сухой доске ставит мелко, на мокрой крупно |
| **Маньяк** | борзый (LAG) | ~45% рук, давит, овербеты до 1.5 банка, блеф — его стихия |
| **Охотник** | эксплойтер | ведёт досье на каждого: блефует тех, кто много фолдит, коллит тех, кто много блефует, не блефует колл-станции |
| **Хамелеон** | непредсказуемый | каждые 15–40 раздач меняет передачу (тайт / луз / ловушки), слоуплеи и чек-рейзы — статистика на него врёт |

## Как они читают блеф

Каждый бот хранит статистику на каждого соперника (`model.js`): VPIP, PFR, агрессия,
как часто фолдит на ставку, и **сколько раз давил на тёрне/ривере и показал мусор** на вскрытии.
Когда соперник ставит, бот строит его диапазон: «вэлью-руки» + доля блефа, которая зависит от
его истории блефов, размера ставки (овербет = поляризация), доски и числа игроков.
Потом считает эквити Монте-Карло против этого диапазона и сравнивает с пот-оддсами.

Насколько бот доверяет статистике — параметр `readSkill` (Скала 0.3 … Охотник 0.92).

## Файлы

- `cards.js` — колода, оценка рук, сила руки префлоп/постфлоп, дро
- `equity.js` — эквити Монте-Карло против диапазонов
- `model.js` — досье на соперников
- `bots.js` — общий мозг + 5 характеров
- `engine.js` — стол: блайнды, ставки, сайд-поты, шоудаун
- `sim.js` — прогон ботов друг против друга

## Запуск

```bash
cd games/poker
node sim.js 2000            # 2000 раздач, итоговая таблица
node sim.js 300 --log       # с логом первых раздач
node sim.js 5000 --seed 42  # воспроизводимый прогон
```

## Как подключить

```js
import { Table } from './engine.js';
import { createBots } from './bots.js';

const players = createBots().map((bot, i) => {
  bot.id = i;
  return { id: i, name: bot.name, stack: 1000, bot };
});
const table = new Table({ players, smallBlind: 5, bigBlind: 10, onEvent: (e) => console.log(e) });
table.playHand();
```

Живой игрок — любой объект с `act(state)`, который возвращает
`{ type: 'fold' | 'check' | 'call' }` или `{ type: 'raise', to: 120 }`.
