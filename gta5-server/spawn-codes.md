Это машины **из самой GTA V** — модов не нужно, работают сразу.
В vMenu: **M** → Vehicle Spawner → Spawn by name, либо через поиск по категориям.

## Полезные команды vMenu

| Действие | Как |
|---|---|
| Открыть меню | `M` |
| Восстановить/починить тачку | Vehicle Options → Fix Vehicle |
| Телепорт к вейпоинту | Misc Settings → Teleport to Waypoint |
| Погода и время | Weather Options / Time Options |
| Оружие | Weapon Options → Get All Weapons |
| Режим бога | Player Options → Godmode |
