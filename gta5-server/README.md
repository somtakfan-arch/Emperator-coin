# FiveM сервер за 10 минут

Готовый комплект чтобы поднять GTA 5 сервер-песочницу для игры с друзьями.
Один скрипт качает всё сам: FXServer, базовые ресурсы, vMenu и пак машин,
пишет рабочий `server.cfg` и создаёт `start.bat`.

Никакого ESX/QBCore, базы данных и RP-обвеса — только песочница: спавн любых
тачек, оружие, телепорт, погода, кастом персонажа.

---

## Что нужно заранее

- Windows 10/11, PowerShell 5.1 (стоит по умолчанию)
- Лицензионная GTA V у тебя и у друзей — **пиратка не подключится**
- У всех установлен [FiveM](https://fivem.net/)
- ~10 ГБ свободного места

## Шаг 1. Ключ (2 минуты)

1. Идёшь на [keymaster.fivem.net](https://keymaster.fivem.net), логинишься через форум Cfx.re
2. **New server** → тип **Development**, IP можно оставить `0.0.0.0`
3. Копируешь ключ — он понадобится через минуту

## Шаг 2. Запуск скрипта (5 минут)

Скачиваешь `setup.ps1` из этой папки, кидаешь, например, в `Загрузки`.
Открываешь PowerShell **в этой папке** (Shift + ПКМ → «Открыть окно PowerShell здесь») и:

```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass -Force
.\setup.ps1
```

Скрипт спросит лицензионный ключ и дальше сделает всё сам:

- скачает актуальный рекомендованный билд FXServer
- развернёт базовые ресурсы (`cfx-server-data`)
- поставит последнюю версию **vMenu**
- скачает пак машин (Bugatti Chiron, Huracan, GTR, Corvette Z06, BMW M4, Mustang, Charger и др.)
- **сам найдёт спавн-имена машин** в `.meta` файлах и пропишет их в `vMenu/config/addons.json`
- напишет `server.cfg` и `start.bat`

Параметры (все необязательные):

```powershell
.\setup.ps1 -Root "D:\FXServer" -Hostname "Emperator crew" -MaxClients 16
.\setup.ps1 -SkipCars          # без пака машин, только ванилла
.\setup.ps1 -SyncCarsOnly      # пересканировать машины после добавления новых паков
```

## Шаг 3. Играем (3 минуты)

1. Запускаешь `C:\FXServer\server-data\start.bat`
2. Ждёшь в консоли строчку про то, что сервер поднялся
3. В FiveM жмёшь **F8** и пишешь:
   ```
   connect 127.0.0.1
   ```
4. В игре **M** → Vehicle Spawner → **Addon Vehicles**

## Как пустить друзей

| Способ | Что делать | Кому |
|---|---|---|
| **Radmin VPN** | Ставите всей компанией, создаёшь сеть, друзья коннектятся `connect <твой_ip_в_radmin>` | Если у тебя серый IP (чаще всего так) — **самый простой путь** |
| **Проброс портов** | В роутере открываешь **30120 TCP + UDP**, друзья пишут `connect <твой_внешний_ip>` | Если IP белый. Пинг лучше |
| **VDS** | Арендуешь за ~5–10 €/мес, ставишь туда | Если хочешь чтобы сервер жил без твоего ПК |

Проверить свой внешний IP: [2ip.ru](https://2ip.ru). Если он не совпадает с тем,
что показывает роутер — IP серый, нужен Radmin VPN.

## Добавить ещё машин

1. Кидаешь папку пака в `C:\FXServer\server-data\resources\[cars]\`
2. Запускаешь:
   ```powershell
   .\setup.ps1 -SyncCarsOnly
   ```
3. Скрипт сам разложит ресурсы по нужной глубине, вытащит спавн-имена и обновит vMenu
4. Дописываешь `ensure <имя_ресурса>` в `server.cfg` (скрипт выведет список) и рестартишь

Где брать бесплатные паки:

- [PLOKMJNB/FiveM-Civ-Car-Pack](https://github.com/PLOKMJNB/FiveM-Civ-Car-Pack) — 161 машина, есть Bugatti Bolide
- [five-m/Vehicles](https://github.com/five-m/Vehicles) — FiveM-ready
- [DEVBenSon/FiveM-Car-Packs](https://github.com/DEVBenSon/FiveM-Car-Packs) — паки до 200+ машин
- [ThatGivensGuy/GIVENS_CARPACK](https://github.com/ThatGivensGuy/GIVENS_CARPACK)
- [gta5-mods.com](https://www.gta5-mods.com/vehicles) — поштучно, но почти всё под сингл, нужна конвертация

> ⚠️ Сайты со «слитыми» платными ресурсами (vag.gg, highleaks и подобные) — мимо.
> Там реально встречаются бэкдоры, которые уводят доступ к серверу.

## Если что-то пошло не так

| Симптом | Причина / решение |
|---|---|
| Машина спавнится как ванильная | В ресурсе потерялась строка `data_file 'VEHICLE_METADATA_FILE' 'data/vehicles.meta'` в `fxmanifest.lua` |
| Машины нет в меню vMenu | Спавн-имя не попало в `addons.json` — прогони `.\setup.ps1 -SyncCarsOnly` |
| `couldn't find resource` в консоли | Ресурс лежит слишком глубоко. FiveM сканирует только папки в квадратных скобках — прогони `-SyncCarsOnly`, он разложит правильно |
| Друзья не коннектятся | Порт 30120 (TCP **и** UDP) закрыт, либо серый IP → Radmin VPN |
| Новые DLC-тачки не спавнятся | Раскомментируй `set sv_enforceGameBuild 3407` в `server.cfg` |
| `Invalid license key` | Ключ не для того IP или тип сервера не Development — сделай новый в keymaster |
| Скрипт ругается на политику выполнения | `Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass -Force` |

## Вариант: хостинг вместо своего ПК

Если не хочешь держать сервер на своей машине — два разных пути.

### А. Игровой хостинг под FiveM (проще)

Панель управления, всё ставится в пару кликов, DDoS-защита, сервер работает
круглосуточно. Дороже за те же ресурсы, но возиться не надо.

| Провайдер | Цена | Заметки |
|---|---|---|
| ZAP-Hosting | от ~$9/мес за 32 слота | Официальный партнёр Cfx.re. Есть пожизненный тариф ~$79 разово — окупается месяцев за 9 |
| RocketNode | от ~$6.5/мес | Самый дешёвый вход |
| Shockbyte | от ~$13/мес | Тарифы по количеству слотов |
| Русские хостинги | от ~800 ₽/мес | Локации Москва/Новосибирск, оплата МИР/СБП — важно если карта РФ |

Рынок в целом: **$6.5–50/мес** в зависимости от слотов и железа.

> Оплата из РФ: зарубежные хостинги иностранную карту требуют почти все.
> Если её нет — бери российский игровой хостинг или VDS с оплатой картой МИР/СБП.

### Б. Обычная VDS (дешевле и гибче)

Берёшь голый Linux-сервер и ставишь FiveM сам — скриптом `setup.sh` из этой папки.
Выходит в 1.5–2 раза дешевле игрового хостинга за то же железо.

**Что брать:** 4 vCPU с высокой частотой (Ryzen), 8 ГБ RAM, NVMe, Debian 12 или Ubuntu 24.04.
FiveM упирается в **однопоточную производительность**, а не в количество ядер — не гонись за 16 слабыми vCPU.

**Установка:**

```bash
ssh root@<ip-сервера>
curl -fsSLO https://raw.githubusercontent.com/somtakfan-arch/Emperator-coin/claude/gta5-rp-server-setup-fvdafy/gta5-server/setup.sh
bash setup.sh
systemctl enable --now fivem
```

Скрипт делает то же, что и Windows-версия, плюс:

- создаёт отдельного системного пользователя `fivem`
- ставит **systemd-юнит** — сервер сам поднимается после перезагрузки и падения
- открывает порт 30120 в `ufw`, если он активен
- показывает внешний IP, на который коннектиться

Переменные окружения (все необязательные):

```bash
ROOT=/srv/fivem HOSTNAME_="Emperator crew" MAXCLIENTS=16 bash setup.sh
SKIP_CARS=1 bash setup.sh          # без пака машин
bash setup.sh --sync-cars          # пересканировать машины
```

Управление:

```bash
systemctl restart fivem      # рестарт
journalctl -u fivem -f       # логи в реальном времени
```

> ⚠️ Порт **30120 TCP и UDP** нужно открыть не только в `ufw`, но и в
> панели/файрволе провайдера — иначе никто не подключится.

### Что выбрать

- **Просто поиграть с друзьями вечерами** → свой ПК + Radmin VPN. Ноль рублей
- **Хочешь чтобы сервер жил всегда, но лень админить** → игровой хостинг
- **Хочешь дешевле и не боишься SSH** → VDS + `setup.sh`

## 📱 Телефон: гараж и автосалон

Ресурс `phone_garage` — свои личные тачки, которые покупаются в приложении и
вызываются на ближайшее парковочное место. Standalone: **не нужен ни ESX/QBCore,
ни MySQL**, всё хранится в JSON рядом с ресурсом.

### Как пользоваться

| Действие | Как |
|---|---|
| Открыть телефон | **F1** (перебиндить: Настройки → Управление → FiveM) |
| Купить машину | Телефон → **Автосалон** → Купить |
| Вызвать машину | Телефон → **Гараж** → Вызвать |
| Убрать машину | Телефон → Убрать в гараж, либо `/park` |
| Продать машину | Телефон → Гараж → Продать (возврат 60%) |
| Баланс | `/money` |
| Выдать денег | `/givemoney <id игрока> <сумма>` — нужен ace `garage.admin` |
| Записать парковку | `/parkhere` — встань/подъедь куда надо и введи |

Стартовый баланс — **$250 000**, меняется в `config.lua`.

### Как работает вызов машины

1. Ищет ближайшее парковочное место из списка в `config.lua` (радиус 400 м)
2. Проверяет, что место свободно — если там кто-то стоит, берёт следующее
3. Подгоняет машину по высоте к реальной земле
4. Если парковок рядом нет — ставит на ближайшую дорогу
5. Если и это не сработало — ставит рядом с тобой
6. Ставит маркер на карту, чтобы машину было видно

### Точность парковок

Координаты в `config.lua` подобраны на глаз — это **не выверенные точки**.
Скрипт подгоняет высоту и пропускает занятые места, так что пара метров в
сторону роли не играет. Но если машина встала криво или в кусты:

```
встань там, где хочешь парковку  →  /parkhere
```

Точка запишется на сервере, разойдётся по всем игрокам и будет работать
наравне с базовыми. Это самый быстрый способ довести список до ума.

### Добавить свои машины в салон

В `config.lua`, секция `Config.Catalog`:

```lua
{ model = 'chiron', label = 'Bugatti Chiron', class = 'Гиперкары', price = 3500000 },
```

`model` — это спавн-имя из пака. Все имена, которые нашёл установщик, лежат в
`spawn-names.txt` в корне установки. После правки: `restart phone_garage`.

### Где лежат данные

| Файл | Что |
|---|---|
| `resources/phone_garage/players.json` | Деньги и гаражи игроков |
| `resources/phone_garage/parking_spots.json` | Парковки, записанные через `/parkhere` |

Привязка к игроку идёт по Rockstar-лицензии, так что прогресс не теряется при
смене ника. Сохранение — при каждой покупке и раз в минуту.

### Безопасность

Все цены и списания считаются **на сервере**. Клиент может только попросить —
купить машину дороже баланса или вызвать чужую тачку не выйдет.

## 🏪 Магазины и карта

Ресурс `ls_shops` — одежда, барбершопы, Ammu-Nation и 24/7. Все точки
отмечены на карте блипами, подходишь к маркеру и жмёшь **E**.

### Что где

| Тип | Точек | Блип | Что делает |
|---|---|---|---|
| Магазин одежды | 12 | Белая футболка | Полный редактор шмота: 15 слотов |
| Барбершоп | 7 | Ножницы | Причёска, цвет волос, мелирование, борода, брови |
| Ammu-Nation | 10 | Пистолет | Оружие и броня за деньги |
| 24/7 / LTD / Rob's | 10 | Магазин | Еда, вода, аптечки, лёгкая броня |
| Парковки | 25+ | Гараж (синий) | Куда подаётся машина из телефона |

Итого **64 точки на карте** из коробки, плюс всё, что допишешь сам.

### Редактор внешности

Открывается в магазине одежды и в барбершопе. Слева панель со слотами,
камера сама встаёт напротив персонажа, изменения видно **сразу**.

- Стрелками `‹ ›` листаешь модель и цвет
- Кнопки «Повернуть» крутят персонажа
- Внизу считается цена: **250 ₽ за слот** в одежде, **150 ₽** в барбершопе
- **Отмена** или `ESC` возвращает всё как было — деньги не спишутся
- **Купить** списывает деньги и сохраняет образ

Слоты одежды: маска, верх, торс и руки, футболка, нашивки, штаны, обувь,
сумка, аксессуар, жилет, головной убор, очки, серьги, часы, браслет.

Борода и брови автоматически красятся в цвет волос — отдельного слота нет.

### Сохранение внешности

Образ хранится на сервере по Rockstar-лицензии и надевается обратно при
заходе и после респавна. Файл: `resources/ls_shops/looks.json`.

### Деньги общие

`ls_shops` не заводит свой кошелёк — он берёт деньги из `phone_garage` через
экспорты. Один баланс на телефон, магазины и всё остальное. Поэтому
`phone_garage` должен быть запущен **раньше** — в сгенерированном `server.cfg`
порядок уже правильный.

### Точность координат

Координаты магазинов — известные общественные точки стоковых магазинов GTA V,
с точностью до пары метров, что радиус маркера перекрывает. Если какая-то
точка встала неудачно:

```
/shophere clothing     (или barber / ammu / store)
```

Записывает точку там, где стоишь, и раздаёт её всем игрокам — как `/parkhere`
для парковок.

### Добавить товары

В `config.lua`, секции `Config.AmmuCatalog` и `Config.StoreCatalog`:

```lua
{ item = 'WEAPON_APPISTOL', label = 'AP Pistol', price = 15000 },
{ item = 'COFFEE', label = 'Кофе', price = 200, heal = 20 },
```

После правки: `restart ls_shops`.

## Файлы

| Файл | Что это |
|---|---|
| `setup.ps1` | Установка на Windows (свой ПК). Один запуск — готовый сервер |
